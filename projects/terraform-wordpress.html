Automating a WordPress infrastructure deployment

A reproducible AWS environment provisioned with Terraform, covering networking, routing, security and compute.

Completed learning projectTerraformAWSVPCEC2Linux
View repository ↗Contact
01 — Challenge

The problem.

The goal was to replace a manual infrastructure setup with a repeatable Terraform configuration that could create the network and compute required to reach the WordPress setup page.

Architecture
InternetIGWPublic subnetSecurity groupEC2 + WordPress
02 — Implementation

How it was built.

  1. 01Defined a VPC using the 10.0.0.0/16 address space and a public subnet at 10.0.1.0/24.
  2. 02Attached an Internet Gateway and configured a route for outbound internet access.
  3. 03Created security-group rules for HTTP and administrative access used by the learning environment.
  4. 04Provisioned an Ubuntu EC2 instance and used user data to install Apache, PHP and WordPress.
  5. 05Verified the deployment by reaching the WordPress setup page from the browser.
terraform · aws
▋
03 — Troubleshooting

What required judgement.

  • Understanding how route tables, Internet Gateways and public subnets work together.
  • Making bootstrapping repeatable rather than configuring the instance manually.
  • Separating a successful learning deployment from the controls that would be required in production.
04 — Result

What worked.

Terraform was able to provision the environment consistently and the WordPress setup page became reachable after instance bootstrap.

05 — Production considerations

What I would change next.

These are improvements I would make for a production-grade implementation; they are not presented as already completed.

  • Move Terraform state to a secured remote backend with locking.
  • Restrict administrative access and avoid broad SSH exposure.
  • Use private application/data tiers where appropriate.
  • Use a managed database rather than keeping application and data concerns together.
  • Add TLS, monitoring, backups and a resilient load-balancing strategy.
