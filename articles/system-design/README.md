# System Design

Articles that break down how applications and infrastructure are designed, how their components interact and why particular technical decisions are made.

Topic ideas are based on the infrastructure-focused learning path in [System Design for DevOps](https://github.com/nabilislam30/system-design-series), with the titles adapted for this article series.

## Planned topics

1. A practical way to think through system design
2. Following traffic from DNS to the VPC
3. Choosing between virtual machines, containers and serverless
4. Matching applications to storage and database options
5. Designing CI/CD for larger platforms
6. Building useful observability into a system
7. Planning for failure and disaster recovery
8. Applying security across the architecture
9. Scaling Infrastructure as Code across environments
10. How container orchestration fits into system design
11. Designing event-driven and asynchronous systems
12. Treating cost as an architecture decision
13. Working through real production design scenarios
